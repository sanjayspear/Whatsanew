# Decision log

| # | Decision | Alternatives | Why |
|---|---|---|---|
| D1 | **The LLM emits an `IntentFrame`; a deterministic `SurfaceComposer` builds the UI** | LLM writes full UI JSON | On the perf floor a 2B INT4 model decodes ~15-25 tok/s. A full surface is 400+ tokens (20 s+); a frame is 30-60. Deterministic composition is testable, consistent, and identical on server. `extraOps` keeps an escape hatch for model-proposed components. |
| D2 | **Tiered engine: rules first, LLM only when unsure** | Always run the LLM | First paint under 300 ms is impossible if it waits for an LLM. Rules handle common phrasings in under 5 ms. The LLM runs on ambiguity only, and never when thermally throttled, so battery cost scales with ambiguity. |
| D3 | **The model never produces content; data comes from the local cache** | RAG-style generated cards | Prevents hallucinated cafés, numbers and showtimes. Makes offline a first-class mode. |
| D4 | **Open component registry: string keys + component-owned JSON props** | Sealed class per component in the DSL | New components need no DSL or renderer change. Unknown keys are warnings, so old apps degrade gracefully against newer models. |
| D5 | **Atomic reducer + validator on every patch** (rules, LLM, server) | Trust the model | One bad op rejects the whole patch and the previous screen stays. Theme values are clamped (type scale 0.85-1.5) for accessibility. |
| D6 | **Cuboctahedron** for the landing solids | Tetrahedron, Rhombicosidodecahedron, Great Icosahedron | Convex, so painter's sort is exact and translucency is correct without OIT (the great icosahedron self-intersects). 14 faces / 12 vertices is ~0.1 ms of CPU projection per frame (the rhombicosidodecahedron's 62 faces read as noise at button size). Squares echo the glass cards; triangles catch highlights. The tetrahedron is too sparse and aggressive. |
| D7 | **Compose Canvas (Skia) for 3D**, not Filament/SceneKit | Filament + SceneKit via expect/actual | 14 polygons don't need a 3D engine. One common codebase, no native view interop, and the solid composites correctly with glass layers. Filament stays an option for a future AR component behind the registry. |
| D8 | **Glass without runtime backdrop blur for cards; Haze only on the floating intent bar** | Backdrop blur everywhere | Blur on every card costs GPU on mid-tier Android (and `RenderEffect` blur is API 31+). Translucent fill over soft ambient orbs reads as glass for free. |
| D9 | **Desktop JVM target as a dev harness** | Emulator-only iteration | The whole shared stack runs and is tested in seconds on any laptop or CI runner. Headless screenshots double as visual-regression baselines. Never shipped. |
| D10 | **Three independent Gradle builds + `build-logic` + one version catalog** | One giant build | Backend CI never configures AGP/Compose, and mobile never loads Spring. Convention plugins keep each new service at ~10 lines. `services/` auto-discovers modules, so service #21 is `mkdir`. |
| D11 | **REST BFF (not GraphQL) at the edge** | GraphQL | The client's query shape is already generated by the DSL (`ListingQuery`), so a second query language would be redundant. REST + ETags + CDN caching suits a geo-bucketed, offline-cache-first client. A batch `surface:resolve` endpoint covers the "many bindings, one round trip" need GraphQL would serve. |
| D12 | **Hexagonal services, enforced by ArchUnit** | Convention only | Layering erodes without enforcement. Domain and application layers import no Spring, Jakarta or Jackson, and CI fails if they do. |
| D13 | **Transactional outbox → Kafka** (Debezium later) | Publish in the request thread | No dual-write: an event exists if and only if the listing committed. `SKIP LOCKED` lets replicas relay in parallel. |
| D14 | **PostGIS `geography` + ISO 3166-2 `RegionCode` partitioning** | Projected coordinates, city enums | Correct distances anywhere on Earth. The region code is the unit of the scale roadmap (BLR → Tier-1 → global). |
| D15 | **Money in minor units + ISO-4217; text as BCP-47 maps; venue time zone per listing** | Doubles, single language, server time zone | Global-ready from day one. "This weekend" resolves in the venue's zone. |
| D16 | **Local DP histograms at root-category granularity; no raw events leave the device** | Upload raw interactions | Private by construction. The server enforces it too (ingestion rejects fine-grained keys and weak ε). The personal ranker stays on-device. |
| D17 | **Signed (Ed25519) model manifests + hashes + staged rollout + smoke-test rollback** | Plain CDN download | A compromised CDN or registry can't push a model. Bad models auto-roll-back on device. |
| D18 | **Swift bridges for Apple Foundation Models / Speech / CryptoKit** | cinterop | These are Swift-only APIs that Kotlin/Native can't call. Swift implements Kotlin interfaces and injects them via `PlatformContext`. |
| D19 | **MapLibre** (not Mapbox) for P1 tiles | Mapbox, Google Maps | BSD-licensed, no per-MAU fees, offline vector tile packs per region. The schematic `MapStack` overlay already works offline today. |
| D20 | **Spring Boot 3.5.x, Kotlin 2.2.21, Compose MP 1.9.3, AGP 8.12, Gradle 8.14** | Bleeding-edge (Boot 4, Kotlin 2.4, AGP 9) | The brief requires Boot 3.x and prefers boring, proven tech. Note: Boot 3.5 OSS support has ended, so see open question Q1. |
| D21 | **Dropped the `iosX64` (Intel simulator) target** | Keep it | Haze no longer publishes it. Apple Silicon Macs are the dev baseline. |
